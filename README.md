# Бурмалдачный Калькулятор и Таймер

## 📋 Выполненные задания:

### 1. Калькулятор (Windows Forms)

**Функции:**
- Стандартные математические операции: `+`, `-`, `×`, `÷`
- Радиобаттоны для выбора операции
- Проверка деления на ноль
- Проверка наличия обоих чисел
- Сохранение результата
- Специальное пасхальное условие: при результате **67** на всех кнопках появляется надпись **"six seven"**

**Использованные элементы:**
- `RadioButton` — для выбора операции
- `TextBox` — для ввода чисел
- `Button` — для расчёта и сброса
- `GroupBox`, `Label`

---

### 2. Таймер (Windows Forms)

**Функции:**
- Обратный отсчёт
- Ввод времени в секундах
- Отображение времени в формате: **ЧЧ:ММ:СС:МС**
- Кнопки: **Запустить**, **Пауза**, **Сбросить**

**Использованные элементы:**
- `Timer` (System.Windows.Forms.Timer)
- `Label` — для отображения времени
- `TextBox` — для ввода секунд
- `Button`
